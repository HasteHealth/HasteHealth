# Model Context Protocol Tools

MCP tools provide structured interfaces for AI agents to perform operations on FHIR resources, execute searches, and interact with the Haste Health platform. Every tool below is returned by a live `tools/list` call — the `resourceType` enums in each input schema reflect exactly what your server's [CapabilityStatement](/docs/api/rest_api/model_context_protocol/endpoint) supports.
