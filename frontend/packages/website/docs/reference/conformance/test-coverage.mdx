# Tested FHIR support

Everything on this page comes from test results, not a feature list. Each
resource type has a FHIR [`TestScript`](https://github.com/hastehealth/hastehealth/tree/main/backend/testscripts/core)
that creates, reads, updates, patches, deletes and searches real data. The same
scripts run against both search backends, **PostgreSQL** and **Elasticsearch**,
and a feature is shown as supported only when its checks pass.
