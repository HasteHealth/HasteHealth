# Conformance

Haste Health's conformance claims come from FHIR `TestScript`s that run in CI on
every change to `main`. Each suite below has its own page with every
TestScript, every check it makes and the latest result, failures and known gaps
included. The scripts themselves are in the public repository under
[`backend/testscripts`](https://github.com/HasteHealth/HasteHealth/tree/main/backend/testscripts).
