# FHIR R4 resources

Every resource type Haste Health stores and searches: the HL7 FHIR R4 core
resources, plus the resources Haste Health adds for its own configuration
(projects, users, access policies). Each page lists the resource's elements and
search parameters. A check mark means the resource passes its conformance
TestScript on both search backends, see [tested FHIR support](/docs/reference/conformance/test-coverage).
